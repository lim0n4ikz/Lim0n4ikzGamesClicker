## 📖 О программе

**Lim0n4ikzGames Clicker** — лёгкая, но многофункциональная программа для автоматического нажатия клавиш и кнопок мыши.

Она создана, чтобы избавить пользователя от утомительных однообразных действий и сэкономить время.

Программа особенно полезна для игр, таких как **Majestic RP**, где игрокам может потребоваться многократно выполнять одни и те же действия:

- копка червей;
- добыча ресурсов;
- рубка леса;
- использование игровых автоматов;
- выполнение повторяющихся действий с быстрыми слотами;
- другие действия, требующие периодического нажатия.

Помимо игр, Lim0n4ikzGames Clicker может использоваться для:

- тестирования программного обеспечения;
- офисной автоматизации;
- демонстрации последовательностей действий;
- повторяющихся операций с клавиатурой и мышью;
- других сценариев, требующих автоматизированного ввода.

# 🚀 Основные возможности

## ⌨️ 4 режима работы

### ⚡ Мгновенное нажатие

Автоматически нажимает выбранную клавишу или кнопку мыши с заданным интервалом.

Поддерживает:

- фиксированные интервалы;
- случайные интервалы;
- клавиши клавиатуры;
- кнопки мыши.

Пример:

```text
F → пауза → F → пауза → F
```

---

### 🔒 Удержание клавиши

Позволяет удерживать выбранную клавишу в течение заданного времени.

Пример:

```text
W → удержание → 2 секунды → отпускание
```

Этот режим полезен, когда клавишу нужно не просто нажать, а удерживать.

---

### 🔄 Последовательное нажатие клавиш

Позволяет создать последовательность из нескольких клавиш.

Пример:

```text
1 → 2 → 3 → F → Space
```

Вы можете настроить задержку между каждым действием.

Это позволяет создавать простые макросы для повторяющихся действий.

---

### ⚡ Мгновенная комбинация

Позволяет нажимать несколько клавиш одновременно.

Примеры:

```text
Ctrl + D
Ctrl + G
Ctrl + Shift + W
Alt + Shift
Shift + W
```

Комбинации можно вводить прямо с клавиатуры.

# ⏱️ Гибкая настройка интервалов

Вы можете указать минимальный и максимальный интервал для автоматических действий.

Пример:

```text
Минимальный интервал: 8.6 сек
Максимальный интервал: 9.0 сек
```

Программа автоматически выберет случайное значение между заданными параметрами.

### Пример

```text
8.73 сек
8.91 сек
8.64 сек
8.97 сек
8.82 сек
```

Это позволяет избежать использования одинакового интервала между каждым действием.

# 🔨 Способы сборки

> ⚠️ **Не рекомендуется для обычных пользователей.**

## Способ 1 — Рекомендованный для Windows

Запустите:

```cmd
build_Lim0n4ikzGamesClicker.bat
```

Вы можете запустить файл двойным щелчком или через командную строку.

## Способ 2 — Вручную

Убедитесь, что PyInstaller установлен:

```bash
pip install pyinstaller
```

Затем выполните следующую команду из корня проекта:

```bash
pyinstaller Lim0n4ikzGamesClicker.spec
```

### 📦 Результат сборки

Скомпилированный файл появится в папке `dist/`:

```text
Windows:
dist/Lim0n4ikzGamesClicker.exe
```

### 📝 Примечания

* Все необходимые файлы, особенно `lim0n4ikzgames.ico`, должны быть доступны в правильном месте для работы `.spec` файла.
* Если возникают ошибки, обновите PyInstaller:

```bash
pip install --upgrade pyinstaller
```

* Чтобы заменить иконку, поместите свой `.ico` файл в корень проекта и обновите параметры `icon` и `datas` внутри `Lim0n4ikzGamesClicker.spec`.
