## 📖 About

**Lim0n4ikzGames Clicker** is a lightweight yet feature-rich application for automatically pressing keyboard keys and mouse buttons.

It is designed to eliminate repetitive actions, save time, and make automation simple and convenient.

The program is especially useful for games such as **Majestic RP**, where players may need to repeatedly perform the same actions:

- digging;
- resource gathering;
- lumberjack activities;
- using slot machines;
- performing repetitive actions with quick slots;
- other actions requiring periodic input.

In addition to gaming, Lim0n4ikzGames Clicker can be used for:

- software testing;
- office automation;
- demonstrating action sequences;
- repetitive keyboard and mouse operations;
- other scenarios requiring automated user input.
