# 🚀 Main Features

## ⌨️ 4 Operation Modes

### ⚡ Instant Press

Automatically presses a selected key or mouse button at a specified interval.

Supports:

- fixed intervals;
- random intervals;
- keyboard keys;
- mouse buttons.

Example:

```text
F → wait → F → wait → F
```

---

### 🔒 Key Hold

Allows you to hold a selected key for a specified amount of time.

Example:

```text
W → hold → 2 seconds → release
```

This mode is useful when a key needs to be held rather than simply pressed.

---

### 🔄 Sequential Key Press

Allows you to create a sequence of multiple keys.

Example:

```text
1 → 2 → 3 → F → Space
```

You can configure the delay between each action.

This allows you to create simple macros for repetitive actions.

---

### ⚡ Instant Combination

Allows multiple keys to be pressed simultaneously.

Examples:

```text
Ctrl + D
Ctrl + G
Ctrl + Shift + W
Alt + Shift
Shift + W
```

Combinations can be entered directly using the keyboard.

# ⏱️ Flexible Interval Settings

You can specify a minimum and maximum interval for automated actions.

Example:

```text
Minimum interval: 8.6 sec
Maximum interval: 9.0 sec
```

The program will automatically select a random value between the specified parameters.

### Example

```text
8.73 sec
8.91 sec
8.64 sec
8.97 sec
8.82 sec
```

This allows you to avoid using exactly the same interval between every action.

# 🔨 Build Methods

> ⚠️ **Not recommended for average users.**

## Method 1 — Recommended for Windows

Run:

```cmd
build_Lim0n4ikzGamesClicker.bat
```

You can launch the file by double-clicking it or through Command Prompt.

## Method 2 — Manual

Make sure PyInstaller is installed:

```bash
pip install pyinstaller
```

Then run the following command from the project root:

```bash
pyinstaller Lim0n4ikzGamesClicker.spec
```

### 📦 Build Output

The compiled file will appear in the `dist/` directory:

```text
Windows:
dist/Lim0n4ikzGamesClicker.exe
```

### 📝 Notes

* All required files, especially `lim0n4ikzgames.ico`, must be available in the correct location for the `.spec` file.
* If you encounter errors, update PyInstaller:

```bash
pip install --upgrade pyinstaller
```

* To replace the icon, place your `.ico` file in the project root and update the `icon` and `datas` parameters inside `Lim0n4ikzGamesClicker.spec`.
