## ✨ Возможности

**Lim0n4ikzGamesClicker** позволяет автоматизировать нажатия клавиш и кнопок мыши.

### 🖱️ Работа с мышью

- Одиночные клики мышью
- Настройка задержки между нажатиями
- Настройка минимального и максимального интервала
- Случайные интервалы между действиями
- Работа с заданными координатами
- Плавное перемещение курсора

### ⌨️ Работа с клавиатурой

- Нажатие отдельных клавиш
- Зажатие клавиш
- Последовательное нажатие клавиш
- Настраиваемые интервалы между клавишами
- Мгновенное выполнение комбинаций
- Поддержка комбинаций вроде:

```text
Ctrl + D
Ctrl + G
Alt + Shift
Shift + W
